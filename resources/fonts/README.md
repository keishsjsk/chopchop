# Шрифты

Шрифты поставляются вместе с программой. Тексты лицензий лежат рядом и попадают в сборки и
в SBOM (`sbom.cdx.json`).

| Файл | Шрифт | Лицензия | Где используется |
|---|---|---|---|
| `Tiny5.ttf` | Tiny5 (The Tiny5 Project Authors, https://github.com/Gissio/font_tiny5) | SIL OFL 1.1, `OFL-Tiny5.txt` | пиксельные заголовки, названия разделов, короткие подписи |

Для остального текста интерфейса используется системный шрифт.

Кириллица в Tiny5 полная (проверено через fontTools: все 66 букв `А–я` и `Ёё`), единица сетки
глифа — 1/8 em, поэтому чётко шрифт рисуется на размерах, кратных 8 пикселям (16, 24, 32).
