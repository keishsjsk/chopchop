# Архитектура

CHOPCHOP — настольное приложение на Python 3.12 и PySide6 (Qt 6). Видео играет libmpv, режет и
кодирует ffmpeg, картинки обрабатывает Pillow. Исходный файл не меняется никогда: редакторы
хранят список операций и применяют его к копии при экспорте.

## Слои

```
core/       чистая модель без Qt-виджетов: операции, геометрия, диапазоны видео, настройки
engines/    ffmpeg, ffprobe, Pillow: превращают модель в пиксели и файлы
editor/     сессии: список операций + отмена и повтор поверх core
services/   настройки на диске, кэш, корзина, журнал, профилирование, временные файлы
workers/    фоновые задачи (экспорт, миниатюры)
player/     обёртка над libmpv (python-mpv) и виджет с OpenGL
viewer/     просмотрщик фото: загрузка, предзагрузка, соседние файлы папки
ui/         окна, страницы, панели, меню; ui/theme — дизайн-система
```

Зависимости идут сверху вниз: `core` ничего не знает о Qt-виджетах и тестируется без экрана;
`ui` знает всех, но логику не содержит — решения принимают сессии и `core`.

## Модель редактирования

- **Фото.** `core/operations.py` — неизменяемые операции (`Crop`, `Rotate`, `Redact`, `Stroke`,
  `Text`, `Adjust`, `Resize` и другие). `editor/session.py` хранит список и стек отмены
  (`core/history.py`); `engines/image_engine.py` применяет список к картинке. Превью считается в
  фоне и кэшируется по списку операций.
- **Видео.** `core/video.py`: `VideoProject` — клипы, звук, эффекты. Клип хранит не одну обрезку,
  а **диапазоны** (см. ниже). `editor/video_session.py` меняет проект операциями
  (`SplitAt`, `RemoveRange`, `RestoreRange`, `set_trim`, `add_text`, …) и ведёт отмену.
  `engines/video_engine.py` и `engines/video_filters.py` строят командную строку ffmpeg.

### Модель диапазонов

`Clip(path, start, end, cuts, splits)`:

| Поле | Смысл |
|---|---|
| `start`, `end` | внешняя обрезка клипа (жёлтые границы) |
| `splits` | точки разреза (клавиша K) |
| `cuts` | вырезанные диапазоны |
| `ranges` | то, что остаётся: `[start, end]` минус `cuts` |
| `ghosts` | вырезанное, оставшееся видимым на полосе (заштриховано, возвращается кликом) |
| `segments` | `ranges`, разбитые `splits`: то, что выделяется и удаляется целиком |

`Clip.to_result(source)` переводит время исходника во время итога, `core/timing.py` — между
клипами проекта. Всё, что привязано ко времени (время показа текста и скрытия области), хранится
**во времени итога**. Когда меняется структура (разрез, вырез, возврат), `timing.retime` сдвигает
окна и возвращает список `TimeNote` (окно схлопнулось или было обрезано), чтобы сказать об этом
пользователю.

### Экспорт видео

- **Быстрый** (без перекодирования): один вызов ffmpeg с concat demuxer и `inpoint`/`outpoint` для
  вырезов внутри одного файла. Начала диапазонов привязаны к ключевым кадрам
  (`engines/keyframes.py`, `core/keyframes.py`). Для клипов из разных файлов — временные куски, потому
  что смешанные контейнеры (mp4 и mkv) в одном вызове ломают шкалу времени.
- **Точный** (с перекодированием): `trim`/`atrim`/`concat` с `setpts=PTS-STARTPTS`; эффекты
  (`enable='between(t,a,b)'` для окон показа) идут в тот же граф фильтров.
- Предпросмотр вырезов не использует EDL: наблюдатель позиции перепрыгивает через вырезы.

Подробности и ограничения: [`cutting.md`](cutting.md).

## Интерфейс

### Главное окно

`ui/main_window.py` держит стек страниц: старт (`drop_zone.py`), просмотр фото
(`viewer/image_viewer.py`), плеер (`ui/video_page.py`), редактор фото (`ui/editor_page.py`) и
редактор видео (`ui/video_editor_page.py`). Окно с нативной рамкой ОС.

### Оболочка редактора

`ui/editor_shell.py` — общий каркас редакторов: верхний ряд (имя файла, отмена, повтор,
«Сохранить»), рейка инструментов слева, контекстная панель параметров, контент, строка состояния.
Страницы наполняют оболочку, но не рисуют рамку сами. Панели инструментов видео строятся лениво
(`_ensure_tools`), чтобы редактор открывался быстро; миниатюры полосы разбирает
`workers/thumbs_worker.py` в фоне с дисковым кэшем (`services/cache.py`), на экране сперва заглушка.

### Реестр действий и контекстные меню

Каждая команда — один `QAction` в `ui/actions.py` (`ActionRegistry`), создаётся в
`ui/main_actions.py`. У действия есть идентификатор, текст, значок, клавиши и **контексты**
(`PHOTO`, `VIDEO`, `PHOTO_EDITOR`, `VIDEO_EDITOR`, `START`). `set_context` включает действия
текущего экрана, поэтому один и тот же Ctrl+C или Delete означает разное на разных экранах и не
конфликтует. Строка меню, кнопки панелей (`bind`), клавиши и контекстные меню используют одни и те
же действия.

`ui/context_menus.py` (`ContextMenus`) собирает меню по месту щелчка: фото, плеер, редактор фото,
редактор видео (полоса обрезки, клипы, чип эффектов). Пункты меню — «двойники» действий реестра
со своим состоянием (доступно, отмечено); клавиши и обработчик остаются у реестра. Меню вызывают
правая кнопка, клавиша Menu и Shift+F10; пока зажата левая кнопка (рамка, кисть), меню не
открывается (`ui/context_gate.py`). `ui/themed_menu.py` рисует меню темой: ступенчатая рамка, жёсткая
тень, появление не дольше 100 мс (с учётом «уменьшить анимацию»).

Файловые команды (копировать, показать в папке, переименовать, удалить, свойства, снимок кадра)
живут в `ui/file_commands.py` и `services/file_ops.py`; удаление только через
`QFile.moveToTrash`, на постоянное удаление код не способен.

### Дизайн-система

`ui/theme/`: токены двух тем и четырёх акцентов (`tokens.py`), таблица стилей только из токенов
(`qss.py`), ступенчатые рамки (`pixel.py`), пиксельные иконки текстовыми битмапами
(`icons.py`, `icon_data.py`; движок иконок создаёт пиксмапы по требованию), шрифт Tiny5
(`fonts.py`), `ThemeManager` с переключением на лету. Подробнее: [`design/README.md`](design/README.md).

## Настройки

`core/settings_schema.py` — единый список настроек с типами, допустимыми значениями и
подписями; `core/settings.py` — чтение, миграции, проверка; `services/app_settings.py` —
файл TOML в папке настроек ОС, атомарная запись, резервная копия при повреждении;
`ui/settings_dialog.py` строится из схемы. `docs/settings.md` генерируется из схемы
(`docs/generate_settings_doc.py`), тест следит, чтобы они не расходились.

## Плеер

`player/libmpv.py` ищет библиотеку, `player/player.py` — тонкая обёртка с типизированным
интерфейсом (дорожки, субтитры, шаги, скриншот, повтор), `player/mpv_widget.py` — `QOpenGLWidget`
с render API. Оформление субтитров — свойства `sub-*` (`core/subtitle_style.py`).
`player/resume.py` запоминает позицию. Окна, плавающие над кадром, живут в `ui/floating.py`.

## Перевод

Все строки идут через `tr()` (или `QCoreApplication.translate` с литералами, их находит lupdate).
Каталог `resources/i18n/chopchop_en.ts` читается напрямую, сборка `.qm` не нужна;
`packaging/update_translations.py` обновляет каталог, тест проверяет, что непереведённых строк нет.

## Профилирование и бенчмарки

`CHOPCHOP_PROFILE=1` печатает время стадий и стек потока интерфейса при зависании дольше 50 мс
(`services/profiling.py`). Воспроизводимые замеры и результаты — в `bench/`; цифры до и после —
в [`performance.md`](performance.md).

## Упаковка

PyInstaller (режим папки, `packaging/chopchop.spec`) включает `resources/` целиком: шрифт, иконки,
переводы; ffmpeg и libmpv кладутся в `resources/bin`. Windows: Inno Setup; Linux: AppImage.
SBOM — CycloneDX из окружения плюс компоненты шрифтов (`packaging/font_components.py`).
