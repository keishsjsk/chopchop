# Ручная проверка перед релизом

Автотесты идут без настоящего экрана (Qt offscreen), поэтому всё, что зависит от оконной системы,
видеокарты и шрифтов ОС, проверяется вручную. Проходите список на собранной программе (установщик,
портативный zip, AppImage), а не на запуске из исходников. Отмечайте результат по каждой системе.

Системы: **W** — Windows 10/11, **X** — Linux X11, **Y** — Linux Wayland (GNOME или KDE).

Подготовка: фото 24 Мп (JPEG), видео 1080p минуты на две с несколькими аудиодорожками, внешний
.srt и .ass, видео mkv и mp4 для склейки, файл с кириллицей и пробелами в имени.

## Запуск и сборка

- [ ] `--version` печатает `CHOPCHOP 0.2.0`, `--self-check` завершается с кодом 0 (в отчёте
  `resources` ok: шрифт, лицензия, перевод, значок на месте).
- [ ] Окно с нативной рамкой ОС; значок в панели задач и в заголовке.
- [ ] «Открыть с помощью» (W) и запуск `chopchop файл` (X, Y) открывают фото и видео.
- [ ] AppImage запускается без установки ffmpeg и libmpv в системе (X, Y).

## Плеер и панели поверх видео

- [ ] Нижняя панель и верхняя панель с названием файла лежат поверх кадра, а не за ним (W, X, Y):
  видны, кликаются, прячутся через 2,5 с без движения мыши и возвращаются при движении.
- [ ] Плавающие панели не мигают чёрными прямоугольниками при появлении и скрытии (особенно Y).
- [ ] Боковая панель дорожек и субтитров открывается поверх кадра.
- [ ] Курсор прячется вместе с панелями и возвращается.
- [ ] Перетаскивание .srt/.ass на окно подключает субтитры.

## Субтитры и шрифты

- [ ] Кириллица и латиница в субтитрах рисуются выбранным шрифтом (поиск шрифта в настройках находит
  системные; образец совпадает с тем, что в кадре) (W, X, Y).
- [ ] На Linux выбранный шрифт действительно применяется libass (fontconfig найден внутри AppImage).
- [ ] Субтитры 1 и 2 одновременно; сдвиг Z/X и Shift+Z/Shift+X.
- [ ] Шрифт Monocraft в программе виден чётко, без размытия, при масштабе экрана
  100, 125, 150 и 200 %.

## Полный экран

- [ ] F, двойной щелчок входят в полный экран, Esc, F, двойной щелчок выходят.
- [ ] Компактная панель (44 px) прячется, остаётся тонкая линия прогресса; наведение возвращает панель.
- [ ] Под панелью нет «дыры» с цветом фона и панель не уезжает за край на втором мониторе.
- [ ] Меню по правой кнопке в полном экране открывается и закрывается Esc, не выходя из полного экрана.

## Контекстные меню

- [ ] Правый щелчок над кадром плеера (OpenGL-виджет) открывает меню (W, X, Y).
- [ ] То же клавишей Menu и Shift+F10; меню появляется у курсора и не выходит за край экрана.
- [ ] Просмотр фото, плеер, редактор фото, редактор видео (полоса обрезки, клипы, эффекты) — у каждого
  свои пункты, у пунктов видны клавиши.
- [ ] «Показать в папке» выделяет файл (W: проводник; X, Y: файловый менеджер).
- [ ] «Удалить» отправляет файл в корзину, а не стирает; после удаления показывается следующий файл.
- [ ] «Копировать как файл» вставляется в проводник или файловый менеджер.
- [ ] Меню не открывается, пока зажата левая кнопка (рамка кропа, кисть).

## Темы и язык на лету

- [ ] Переключение светлая / тёмная / системная в настройках перекрашивает всё сразу, включая
  открытый редактор, панели поверх плеера, значки и меню, без перезапуска.
- [ ] Смена акцента (4 цвета) тоже на лету.
- [ ] Смена темы ОС при выбранной «Системной» подхватывается (W, X, Y).
- [ ] Русский и английский интерфейс: ни одной непереведённой строки в меню, окнах и подсказках.

## Редакторы

- [ ] Фото: кроп, поворот, скрытие области, кисть, текст, цвет, размер; отмена и повтор; сохранение
  рядом как `имя_edited.jpg` без EXIF.
- [ ] Видео: разрез K, удаление сегмента, возврат вырезанного кликом по «призраку», склейка двух
  роликов, громкость, замена звука, текст и скрытие области со временем показа.
- [ ] Быстрый экспорт: один файл, начало сдвигается к ключевому кадру, воспроизводится без рывков.
- [ ] Точный экспорт: границы точны до кадра, звук синхронен, прогресс и отмена работают.
- [ ] Экспорт с NVENC / Quick Sync / AMF, если есть видеокарта; при ошибке кодера возвращается на процессор.

## Производительность (по `bench/`, см. `docs/performance.md`)

- [ ] `python bench/bench_photo.py --size 24MP --repeat 5` — все замеры `ok` в пределах бюджета.
- [ ] `python bench/bench_video.py` — открытие редактора, блокировка потока интерфейса меньше 50 мс.
- [ ] На живом окне: перетаскивание рамки кропа и штрих кисти по 24 Мп фото идут плавно (60 кадров/с).
- [ ] `CHOPCHOP_PROFILE=1` не показывает `event loop stalled` при обычной работе.

## Что известно, но не проверено автоматически

- Linux X11 и Wayland: оконная часть (панели поверх OpenGL, правый щелчок над плеером, шрифты
  субтитров) проверена только на Windows; по этому списку нужно пройти на Linux до релиза.
- Умная резка (перекодировать только края) не сделана; быстрый режим режет по ключевым кадрам.
